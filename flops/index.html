▸3 训练时间：token 预算 ↔ 天数，两头都能定
每个 token 的训练成本 = 3·F / T F 和 3× 见第 1 段，这里直接用 总算力 = 每 token 成本 × D D = 目标 token 数 有效算力 = 峰值 × MFU × 卡数 天数 = 总算力 / 有效算力 反过来：D = 天数 × 有效算力 × T / (3·F)

为什么 MFU 打不满：arithmetic intensity

AI = FLOPs / 从显存搬运的字节数 [FLOP/byte] 机器平衡点 = 峰值算力 / 显存带宽 AI > 平衡点 → compute-bound（算力吃满） AI < 平衡点 → memory-bound（在等数据）
